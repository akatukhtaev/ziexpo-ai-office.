# Ziexpo AI Office

Стартовый веб-прототип виртуального офиса для YouTube-канала Ziexpo.

## Запуск локально

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Текущий статус

- [x] Адаптивный интерфейс для компьютера и телефона
- [x] Пиксельная карта офиса и интерактивный выбор агента
- [x] Карточка выбранного агента и стартовая сводка
- [ ] Серверная база задач и общей памяти

## Архитектура следующих этапов

Frontend: Next.js  
Hosting: Cloudflare Pages (или Workers с поддержкой Next.js)  
Backend: Cloudflare Workers / Node.js API  
Storage: Cloudflare D1  
AI orchestration: отдельный координатор и специализированные роли

Важно: текущая версия — интерфейсный прототип. Агенты пока не выполняют реальные AI-задачи и не публикуют видео.
